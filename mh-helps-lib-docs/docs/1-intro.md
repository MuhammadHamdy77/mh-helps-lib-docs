# mh-helps-lib

📦 **mh-helps-lib** is a lightweight Angular utility library that provides custom validators, directives, pipes, services, and dynamic components to simplify form handling and UI development.

---

## ✨ Features
- ✅ Dynamic Icon Component & Service
- ✅ Dynamic Form Component
- ✅ Image Optimization Component & Service
- ✅ Lang Pipe (AR/EN Switch)
- ✅ SAR Currency Pipe
- ✅ IBAN Format Pipe
- ✅ Validation Directives (`TrimWhiteSpaces`, `NumbersOnly`, `LeadingStart`)
- ✅ Custom Validators
- ✅ Hijri Date Utils
- ✅ Encrypt/Decrypt Utility
- ✅ Language Service
- ✅ Helpers (attachBaseUrl, etc.)
